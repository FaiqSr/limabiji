# Origin Page (`/origin/{name}`) — Nordic Approach Style

> **For Hermes:** Implement task-by-task. Each task is bite-sized (2-5 min).

**Goal:** Redesign the `/origin/{name}` page from a broken stub (extends wrong layout, no content) into a full Nordic Approach-style origin detail page with full-bleed hero image, city name centered over the image, and origin-specific coffee information.

**Architecture:** Laravel Blade. The page extends `layouts.landingpages`. Data for each origin (Bogor, Bandung, Malang, Toraja, Aceh, Yogyakarta) is defined in a PHP array in the controller. The view receives `$origin` data and renders dynamically.

**Tech Stack:** Laravel + Tailwind CSS v4 + Bebas Neue + Rubik (same as rest of site).

---

## Current State

**File:** `resources/views/landingpages/origins.blade.php` (14 lines, broken)

Problems:
- Extends `landingpages.index` instead of `layouts.landingpages` — causes infinite nesting
- No hero section
- Broken `class="w-"` (invalid Tailwind)
- Placeholder image only — no text, no info
- Controller passes only `$name` string, no rich data

**Route:** `Route::get('/origin/{name}', [LandingPages::class, 'origins'])`
**Controller:** `origins(string $originName)` returns `view('landingpages.origins', ['name' => $originName])`

**Linked from:** Homepage Swiper carousel — 6 origins: Bogor, Bandung, Malang, Toraja, Aceh, Yogyakarta

## Design

### Hero — Full-Bleed Image + City Name Centered

```
┌──────────────────────────────────────────────┐
│                                              │
│           [FULL-BLEED IMAGE]                 │
│           coffee farm / landscape            │
│                                              │
│              ┌──────────────┐                │
│              │   BOGOR      │ ← Bebas Neue   │
│              │ West Java    │   10rem, white  │
│              └──────────────┘                │
│                                              │
│         "High-altitude Arabica..."           │
│                                              │
└──────────────────────────────────────────────┘
```

- Full-bleed image: `h-[70vh]` with dark overlay gradient
- City name: `font-display text-7xl sm:text-[10rem]` centered absolute
- Subtitle: province name below city
- Scroll indicator at bottom

### Content Sections

1. **Overview** — 2-3 sentences about the origin's coffee heritage
2. **Key Stats** — glassmorphism card grid: Altitude, Varietals, Process, Harvest Season, Cupping Score
3. **Partner Farms** — list of farms in this origin (if data available)
4. **Flavor Profile** — tasting notes, body, acidity
5. **CTA** — "Request samples from {{ origin }}" → contact page

## Risks & Tradeoffs

1. **Images:** Using Unsplash placeholder images. Replace with real farm photos later.
2. **Data hardcoded:** Origin data is in the controller array. If the project grows, migrate to a database or config file.
3. **404 handling:** Invalid origin names return a 404. The homepage carousel only links to valid names, so this is a safety net.
4. **Mobile:** Hero image is `h-[70vh]` — sufficient for all screen sizes. Stats grid wraps to 2 columns on mobile.
